# wit

Canonical WIT package roots live under `wit/v0.0.4/` (experimental) and
`wit/v1.0.0/` (frozen) as separate single-package directories:

- `finstack-ai-types/types.wit`
- `finstack-ai-host/host.wit`
- `finstack-ai-toolset/toolset.wit`
- `finstack-ai-context/context.wit`

Bindings are generated by `scripts/wit_bindgen/generate.py` from both
majors. Worlds stay coarse: `list-tools`/`call` and `collect` only.

Fixtures use the same semver segment:
`fixtures/compatibility/wit/v0.0.4/` and
`fixtures/compatibility/wit/v1.0.0/`.
