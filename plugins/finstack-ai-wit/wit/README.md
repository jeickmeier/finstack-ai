# wit

Canonical experimental WIT package roots live under `wit/v0.0.4/` as
separate single-package directories:

- `finstack-ai-types/types.wit`
- `finstack-ai-host/host.wit`
- `finstack-ai-toolset/toolset.wit`

`context.wit` is owned by PR-050 and is not created here. Bindings are
generated by `tools/wit_bindgen/generate.py`.

Fixtures use the same semver segment:
`fixtures/compatibility/wit/v0.0.4/<kind>/<valid|invalid|roundtrip>--<slug>.<ext>`.
