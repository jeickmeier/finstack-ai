# Public RFCs

Ecosystem-facing contract changes require a public RFC **in addition to**
an ADR. That includes journal schemas, event order, WIT worlds, and remote
or process protocols.

Architecture decisions stay in
[`docs/implementation/adrs/`](../implementation/adrs/) and the
[ADR register](../implementation/adr-register.md). An RFC does not replace
an ADR.

## How to propose

1. Copy [0000-template.md](0000-template.md).
2. Number the next RFC in this directory.
3. Link the RFC from the matching ADR and from the pull request.
4. Dual-license remains `MIT OR Apache-2.0`. Commits stay DCO-signed.
   There is no CLA.
