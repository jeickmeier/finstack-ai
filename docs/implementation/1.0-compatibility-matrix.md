# 1.0 compatibility matrix

Adopter-facing table of frozen families versus experimental exclusions
at lockstep `1.0.0` (local tag `v1.0.0`; registries unpublished).
This file does not replace
[`1.0-compatibility-policy.md`](1.0-compatibility-policy.md) or
[`compatibility-governance.md`](compatibility-governance.md). It is not
the G8 decision and is not a registry publication.

Package versions: crates, Python wheel, and `@finstack/ai` are
**`1.0.0`**. Permanent WIT worlds are **`finstack:ai-*@1.0.0`**.

## Frozen families

| Family | Package / world | Unknown-field / evolution |
| --- | --- | --- |
| Public Rust API (kernel / runtime / SDK) | `finstack-ai` `1.0.0` | Semantic renames and removals are major |
| Python public modules and exceptions | `finstack-ai` wheel `1.0.0` | New exports may be additive; removals are major |
| JS/TS exports and WASM host ABI | `@finstack/ai` `1.0.0` | New exports may be additive; removals are major |
| AgentSpec / BundleSpec / locks | lockstep `1.0.0` | Strict reject-unknown; additive fields need a version or default |
| Journal records / snapshots | candidate-v1 | Unknown state-bearing fields and kinds are fatal |
| Runtime events (durable-derived) | lockstep `1.0.0` | Durable-derived payloads follow the durable unknown-field rule |
| Remote protocol | lockstep `1.0.0` | Inbound reject-unknown; version handshake |
| Process family | handshake-only | Session vocabulary is later and is not frozen |
| WIT `finstack:ai-types/host/toolset/context@1.0.0` | `@1.0.0` | Exact worlds; unknown world or undeclared field fails closed |

## Experimental exclusions

These surfaces have **no** permanent 1.0 promise and must stay labeled:

| Surface | Label |
| --- | --- |
| IndexedDB host journal | inspect-not-continue; not NFR-REL-001 |
| WIT `@0.x` after the freeze | loadable, not the permanent world |
| Observer isolation / WIT observer worlds | needs a later ADR |
| Process-plugin session commands | do not exist; handshake-only |
| SharedArrayBuffer / cross-origin isolation | ADR-031 |
| Marketplace, native dylib ABI, PostgreSQL, exactly-once | excluded |
