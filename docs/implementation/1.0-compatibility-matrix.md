# 1.0 compatibility matrix

Adopter-facing table of frozen families versus experimental exclusions
at lockstep `1.0.0` (local tag `v1.0.0`; registries unpublished).
This file does not replace
[`1.0-compatibility-policy.md`](1.0-compatibility-policy.md) or
[`compatibility-governance.md`](compatibility-governance.md). It is not
the G8 decision and is not a registry publication.

Package versions: crates, Python wheel, and `@finstack/ai` are
**`1.0.0`**. Permanent WIT worlds are **`finstack:ai-*@1.0.0`**.

## Frozen families

| Family | Package / world | Unknown-field / evolution |
| --- | --- | --- |
| Public Rust API (kernel / runtime / SDK) | `finstack-ai` `1.0.0` | Semantic renames and removals are major |
| Python public modules and exceptions | `finstack-ai` wheel `1.0.0` | New exports may be additive; removals are major |
| JS/TS exports and WASM host ABI | `@finstack/ai` `1.0.0` | New exports may be additive; removals are major |
| AgentSpec / BundleSpec / locks | lockstep `1.0.0` | Strict reject-unknown; additive fields need a version or default |
| Journal records / snapshots | candidate-v1 | Unknown state-bearing fields and kinds are fatal |
| Runtime events (durable-derived) | lockstep `1.0.0` | Durable-derived payloads follow the durable unknown-field rule |
| Remote protocol | lockstep `1.0.0` | Inbound reject-unknown; version handshake |
| Process family | handshake-only | Session vocabulary is later and is not frozen |
| WIT `finstack:ai-types/host/toolset/context@1.0.0` | `@1.0.0` | Exact worlds; unknown world or undeclared field fails closed |

## Experimental exclusions

These surfaces have **no** permanent 1.0 promise and must stay labeled:

| Surface | Label |
| --- | --- |
| IndexedDB host journal | inspect-not-continue; not NFR-REL-001 |
| WIT `@0.x` after the freeze | loadable, not the permanent world |
| Observer isolation / WIT observer worlds | needs a later ADR |
| Process-plugin session commands | do not exist; handshake-only |
| SharedArrayBuffer / cross-origin isolation | ADR-031 |
| Marketplace, native dylib ABI, PostgreSQL, exactly-once | excluded |

## Pre-publication 1.0.0 classifications

Nothing in this table has shipped to crates.io / PyPI / npm
(`CHANGELOG.md` `## [Unreleased]`). These are source-breaking relative
to local tag `v1.0.0` and are classified now so the freeze gate can see
them. They are **1.0.0 pre-publication** — allowed because unpublished.
Do not invent a major bump.

| Surface | Change | Class | Cross-surface |
| --- | --- | --- | --- |
| `SessionRuntime::existing` | `Option<Arc<Self>>` → `Result<Option<Arc<Self>>, SessionError>` | Source-breaking; 1.0.0 pre-publication | Rust only. Python/JS do not expose this inherent method. |
| `AgentRunRequest.capability` | Additive `pub` field; struct-literal break | Source-breaking; 1.0.0 pre-publication | Rust only. `#[non_exhaustive]` is now on the struct so the next field is not another silent break. Use `try_new`. |

## Planned additive 1.0 surfaces (Phase 12)

Authorized by Implementation Plan 0.22 / pack v0.24. These are **additive** or **new-package**. The freeze gate (`tools/compat/public_items.py --check`) already fails on added names and Rust signature drift (B1). Do not land a surface without a `--write` baseline update in the same change. Do not treat these as 1.0.x patches that hide from the gate.

| Surface | Change | Class | Owner |
| --- | --- | --- | --- |
| ContextProvider production driver | Internal runtime driver; Python adapter becomes reachable | Additive runtime/SDK | PR-075 |
| `finstack-ai-workflow-local` | Restored package plus adapter-owned cron trigger API | New package | PR-076 |
| `Lane::run` / `suspend` / `resume` | Additive inherent methods on existing `Lane` | Additive SDK | PR-077 |
| Python `Lane` / `Session` handles | Additive `cancel`, `append_text`, `lane_by_id`, `run`, `suspend`, `resume`; `SqliteDurability` | Additive Python | PR-078 |
| `AgentRun` child-run / `complete_external` | Additive Rust methods, then Python routing | Additive Rust then Python | PR-079 |

Journal `RecordBody`, WIT worlds, and remote-protocol meaning stay frozen. NFR-PORT-* is unchanged in this authorization.
