## Labeled, not deprecated

These are experimental exclusions, not removal-scheduled APIs:

- IndexedDB host journal — experimental / non-durable
- WIT `@0.x` after this freeze — loadable through adapters; not the
  permanent world. Guests retarget to `@1.0.0` using
  [`plugins/finstack-ai-guest-sdk/MIGRATION.md`](../../plugins/finstack-ai-guest-sdk/MIGRATION.md)
- Process session vocabulary — does not exist; handshake-only
- wasm-bindgen `initSync` positional parameters — toolchain-generated
  warning in `bindings/finstack-ai-wasm/js/generated/`; not a
  first-party public alias

## Rule for later deprecations

1. Record the row here and in the changelog `Deprecated` section.
2. Name `since` and a removal version (`2.0.0` or a dated 1.x).
3. Keep the alias until that version.
4. Source the deprecation from reviewed feedback or a classified
   contract change, not invention.
