Triggered controls: Threat Model section 18 (workflow /
application boundary). Primary TM-19. Also TM-10 / TM-14
(retry and timer/cancel already proven; adapters must not
bypass them) and SEC-INV-002/003/004/007/008.

PASS  TM-19 locator / tenant
      Tenant scope is taken from recovered RunAccepted, not from
      a user-selected ownership field. Locator mismatch and
      recover failure both surface as unknown_locator without
      confirming existence. Cross-tenant
      ExternalEffectCompletionCommand is denied with
      unknown_locator.

PASS  TM-10 retry policy
      retry_decision is the only legal re-dispatch ask. It
      composes outstanding effect identity, RetrySafety,
      model_retry_allowed / tool_retry_allowed, and
      RunLimits.max_retries. Deny codes are
      retry_limit_reached, retry_not_safe, and
      effect_not_outstanding. A Deny does not enqueue
      ExecuteEffect. Temporal-shaped policy N cannot exceed
      kernel max_retries.

PASS  TM-14 timer / cancel / deferred
      Durable sleep parks on a committed timer EffectId and
      advances only through ExternalClock. Worker restart
      restores the same EffectId / InteractionId / due_at.
      Ingress for external completion and interaction
      resolution reuses the existing routers.

PASS  SEC-INV-002/003/004 no seventh port / no kernel I/O
      Six ports stay Model / Toolset / ContextProvider /
      Middleware / JournalStore / Observer. No AwaitingWorkflow
      phase, no workflow record families, no kernel DAG.
      Workflow crates do not depend on the kernel crate in
      [dependencies]. Default kernel / runtime / SDK / wit /
      wasm / native-examples do not depend on workflow crates,
      temporalio, or restate-sdk.

PASS  SEC-INV-007/008 no vendor SDK / no secret handles
      No temporalio, Restate, or DBOS SDK in workspace.deps.
      Checkpoints store tenant/session/lane/run/seq plus
      optional non-secret ExternalHandleRef only. Journal
      sequence always wins over a conflicting hint.

Residual: hosted matrix / cargo-deny / gitleaks not claimed.
recover_run filtered replay remains unused because it fails
journal_replay_failed on these journals; restore uses
CommitCoordinator::recover plus run-id checks. No G7-D.
