Triggered controls: TM-15 primary; secondary TM-12 and TM-19.
SEC-INV-004, SEC-INV-008, SEC-INV-010.
No new primary port. Recover stays replay-only. The conversation
tree remains a session-level projection, not KernelState.

PASS  TM-15 / child-run identity, mapping, and fan-out
      ChildRunPrepared remains the durable parent-effect → child
      locator mapping. CompatibleLane children must already exist
      as a public lane (unknown_child_lane). IsolatedChildSession
      children remain a different SessionId. Parent cancel walks
      child_mappings and submits CancelRequested { initiator:
      ParentRun { parent_run_id } } or Deadline when
      MinimumOfParentAndChild applies. Detach-preauthorized
      children are not cancelled. RemoteChildSession is vocabulary
      only. Lanes are not treated as lineage. One kernel equals
      one run; concurrent siblings are N coordinators sharing one
      SessionRuntime / store.

PASS  SEC-INV-008 / identity not substituted
      Scoped recover applies only the target run's records onto an
      empty kernel and still advances last_applied_sequence to the
      session head. A sibling Conflict reload cannot become the
      main kernel. ChildRunPrepared envelopes keep the parent
      run_id. Session metadata and the host identity map never
      grant journal authority.

PASS  SEC-INV-004 / duplicates idempotent, conflicts fail closed
      A second owner of (session_id, lane_id) is LaneBusy. Store
      compare-and-append remains the cross-process linearizer.
      Equal identity-map bind is idempotent; a different
      (session_id, lane_id) is Conflict. Equal child mapping retry
      remains idempotent; a conflicting remap is SidecarConflict.
      CancelRequested is at-least-once plus idempotent.

PASS  SEC-INV-010 / journal remains authoritative
      Snapshots are used only when the snapshot's accepted run
      matches the recover target. Non-primary recoveries disable
      snapshot writes. Session::open rebuilds the projection and
      does not auto-respawn parked runs. Pre-046 journals without
      SessionCreated still open. Journal v1 family count stays 40.
      Existing v1–v6 kernel-state hashes and LaneMoved /
      EntryAppended / ConversationEntry wire shapes are unchanged.

PASS  TM-12 secondary
      Structural records use the existing checksum/encoding
      policy. Sequence is the shared session envelope sequence.
      SQLite A04 proves parallel lane appenders do not tear a
      batch or reuse a sequence. Crash-prefix remains PR-048.

PASS  TM-19 secondary
      ExternalIdentityKey rejects empty, oversized, or NUL labels.
      The map is host-owned and is not journaled. Bind requires
      the lane to exist in this session. Conflicting bind fails
      closed. No channel/gateway product is added.

existing checksum/encoding policy, and at-least-once plus
idempotency. Residual already recorded in the threat model:
crash-prefix and WASM durable restart remain PR-048. ADR-012,
ADR-016, and ADR-026 stay Partial. ADR-013 stays Not started /
