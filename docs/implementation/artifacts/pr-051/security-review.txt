PASS  TM-07 / trap containment and explicit linked capabilities
      Guest unreachable and Wasmtime Trap downcasts map to plugin_trap.
      The host continues and can create another Store. Instantiation
      links only logging and blobs. A component that imports
      wasi:cli/exit@0.2.0 fails as plugin_instantiate_failed. This is
      fail-closed absence of WASI, not a grant. Epoch interruption is
      the cancellation channel only; it is not a resource-limit claim.

PASS  TM-08 / compiled-cache identity
      Cache key material is host-owned JCS of {abi, digest, engine,
      target} then SHA-256. digest is SHA-256 of component bytes, not
      the PR-050 manifest digest. engine is 47.0.3 plus
      async=true,epoch=true,compiler=cranelift. target includes os,
      arch, and cranelift ISA. abi includes the world plus the
      experimental @0.0.4 package set. Hits deserialize this engine's
      precompile_component output. Independently changing any field
      misses. Wasmtime's implicit filesystem cache feature is off.
      No lockfile scan and no publisher-signature verify.

PASS  TM-06 / trust labels
      PluginHost and adapters are labeled isolated Wasmtime (T3).
      finstack-ai-wit in-process adapters continue to say they inherit
      host authority and are not a sandbox. ExtensionDescriptor still
      uses trusted_in_process because ExtensionTrust has no isolated
      variant; isolation is a property of PluginHost. Default SDK
      bundles do not depend on the host.

PASS  ADR-010 / optional isolation leaf
      Wasmtime lives only in plugins/finstack-ai-plugin-host.
      Constructing PluginHost is the opt-in. No default SDK feature
      pulls the crate. This is the first real T3 leaf; G6 remains.

PASS  ADR-011 / no native dylib ABI
      No dylib loader, libloading, or native plugin path was added.

PASS  ADR-035 / experimental 0.x
      Packages stay @0.0.4. Crate version stays 0.0.3. @1.0.0
      generation remains blocked. Coarse list-tools/call/collect; no
      component resources or progress streams. G6 owns Implemented.
