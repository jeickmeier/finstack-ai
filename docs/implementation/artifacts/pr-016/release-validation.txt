Release policy

- Cargo release panic policy changed from abort to unwind. This is required for
  a native Toolset panic to be converted to a stable per-call failure without
  terminating the run process.
- Containment is placed at the direct native extension boundary, not around the
  runtime worker. The outer scheduler and sibling calls survive.
- Dropping the owner aborts the inner unwind boundary so an extension task
  cannot detach from the owned JoinSet.
