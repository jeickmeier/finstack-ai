Triggered controls: TM-12 core; also TM-04, TM-10, TM-16, TM-18;
SEC-INV-007; SEC-INV-010. TM-09 remote framing remains PR-058.

PASS  TM-12 / SEC-INV-010 journal integrity
      Append uses one BEGIN IMMEDIATE transaction. Batch/record identity
      is checked before expected_sequence. Load and scan reconstruct
      envelopes, call verify_chain, and require sessions.head_checksum
      to match. Unknown user_version and PRAGMA quick_check failures
      fail closed. Corrupt/not-a-db files map to sqlite_corrupt or a
      closed unavailable error. Checksums still do not authenticate a
      coordinated rewrite of records plus the head.

PASS  TM-16 / SEC-INV-007 bounded resources
      SqliteStoreLimits reject zero ceilings. Scan limit 0 is invalid;
      page max remains 256. Decode uses the protocol envelope ceilings.
      busy_timeout is required and non-zero. One Mutex<Connection> owns
      the writer; there is no pool.

PASS  TM-10 compare-and-append identity
      Exact batch_id reuse returns the original receipt or
      append_batch_id_reuse. Record-id reuse follows the memory-store
      mixed/exact rules. Same-instance second writers get Conflict.
      A second connection that hits SQLITE_BUSY after busy_timeout
      returns sqlite_busy. AmbiguousAckAfterCommitStore retries the
      original sqlite receipt.

PASS  TM-04 journal secret surface
      The store persists typed records and session metadata. Metadata
      CAS never grants authority. No provider credential field, no
      SQLCipher, and no default Agent/Python/WASM wiring were added.

PASS  TM-18 new crate dependency
      rusqlite 0.37.0 with the bundled feature is pinned in
      workspace.dependencies and Cargo.lock. The crate is a trusted
      native leaf. cargo tree -e normal for finstack-ai-runtime,
      finstack-ai, and finstack-ai-kernel does not include rusqlite
      or finstack-ai-store-sqlite. tools/wasm_package/check.py graph
      still forbids rusqlite in wasm-host graphs. mise.toml has no
      supply-chain task and deny.toml is absent; this review records
      the pin and graph checks, not a cargo-deny pass.

Residual already recorded:
  Checksums detect accidental corruption and unsynchronized edits.
  They do not authenticate history against an attacker who rewrites
  records, metadata, snapshots, and the head together.
  SQLite acknowledgement depends on the OS/filesystem honoring
  WAL+FULL (Threat Model §16). Relaxed NORMAL/OFF and :memory:
  stay health().durable = false and must not advertise NFR-REL-001.
  Encryption/SQLCipher, full crash-prefix, migrators, IndexedDB v1,
  snapshot acceleration, and G5 remain later PRs.
