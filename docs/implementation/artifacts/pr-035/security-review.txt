PASS  Handle lifetime matches Python
      Dropping a Run detaches observation only. cancel() is explicit and
      idempotent. closeEvents() / iterator abort close delivery only.
      After cancel, HostModel/HostToolset AbortControllers abort on drop
      so hanging host promises settle. A04 proves pending host requests
      return to zero and a dropped second run does not cancel the first.

PASS  Explicit snapshots only
      Session/RunResult getters do not serialize the journal. toDict,
      toJson, toJsonBytes, and EventBatch.events() are the snapshot
      paths. A02 asserts matching repeated snapshots.

PASS  Stable error codes and redaction
      FinstackError carries agent_run_invalid_configuration,
      agent_run_timeout, agent_run_cancelled, agent_run_runtime_failure,
      and agent_run_unsupported_plan. Durable diagnostics stay free of
      raw JS exception text (existing js_host_* mapping). Cancelled
      results include the session locator, not host exception text.

PASS  Trust class and persistence
      JS adapters remain trusted T2. Default journal is process-local
      Rust MemoryJournalStore. JS createMemoryJournalStore() stays a
      pre-beta health stub. No IndexedDB, worker, or SQLite surface.
      Agent.create does not accept a JS journal.

PASS  Selected wasm production graph
      check-wasm requires finstack-ai-store-memory and still rejects
      Tokio, reqwest, rusqlite, pyo3, wasmtime, and the Rust OpenAI
      provider. finstack-ai-test is not a wasm production dependency.
      Secret scan of js/src, README, harness, and generated glue found
      no credential-field or provider-secret pattern.

PASS  No G4 / adapter flip
      DeferredBindingAdapter::wasm() remains Unavailable. No
