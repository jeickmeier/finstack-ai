SEC-INV-004, SEC-INV-008, SEC-INV-010.
No new primary port. Recover stays replay-only. The conversation
tree is a session-level projection, not KernelState.

PASS  TM-15 / child-run identity and mapping
      ChildRunPrepared remains the durable parent-effect → child
      locator mapping. Kernel apply rejects a conflicting
      preparation (InvalidRecordOrder). start_or_attach consults
      SessionProjection.child_mapping and returns SidecarConflict
      on digest/locator/placement mismatch; equal retry is
      idempotent. CompatibleLane and IsolatedChildSession mappings
      survive recover and match the restored RunRelation.
      ChildRunPrepared envelopes keep the parent run_id. Same-
      session child RunAccepted does not apply onto the parent
      kernel; last_applied_sequence still advances. Lanes are not
      treated as lineage. No cancel, deadline, or budget fan-out
      is added (PR-047). RemoteChildSession dispatch is not added.

PASS  SEC-INV-008 / identity not substituted
      ConversationEntry identity shares message UUID bytes.
      Sibling ConversationEntry RecordId uses those bytes;
      LaneMoved RecordId is a deterministic xor of the same
      bytes. EntryId reuse with a different parent_id or body is
      conversation_immutable. ConversationEntry rejects a run_id
      on the envelope. Unknown foreign run_id still fails closed;
      only a known child preparation or a child RunAccepted is
      skipped. Session metadata never grants authority.

PASS  SEC-INV-004 / duplicates idempotent, conflicts fail closed
      Equal ConversationEntry replay (same id, parent_id, lane_id,
      body) is idempotent even when the envelope sequence differs.
      A rewrite fails closed before append (preview_session_records).
      A second root AcceptRun while main is busy is rejected.
      Conflicting child remap is SidecarConflict. Incomplete or
      duplicate tool-call pairs fail extract_history.

PASS  SEC-INV-010 / journal remains authoritative
      Snapshots are not authoritative. Dropping SnapshotWritten /
      snapshot bytes / accelerated restore rebuilds the same tree
      from the journal. Pre-046 journals without SessionCreated
      still load. Existing v1–v6 kernel-state hashes and
      EntryAppended / LaneMoved wire shapes are unchanged.
      ConversationEntry is omitted from kernel-state hash.

PASS  TM-12 secondary
      Structural records use the existing checksum/encoding
      policy. Sequence is the envelope sequence. lane_id must
      match the envelope. Corrupt identity substitution still
      fails closed. Crash-prefix and WASM durable restart remain
      PR-048.
