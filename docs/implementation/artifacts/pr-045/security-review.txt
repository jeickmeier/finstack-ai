No new primary port. Recover stays replay-only. Timer identity is

TimerFired.effect_id.

PASS  TM-14 / late privileged effect or completion
      CancellationRequested commits before CancelEffect signalling.
      Outstanding set includes the interaction effect and retry
      timer, so Sleeping/AwaitingInteraction cannot RunCancelled
      while those waits remain. TimerFired after cancel is
      invalid_phase_input and does not start a cycle. Late
      InteractionSettled after run-level cancel is rejected;
      InteractionRouter records ExternalCommandRejected. In-flight
      model/tool completions are not drained as idle; deferred
      Unknown/AtMostOnce suspends as cancellation_uncertain.
      Framework-authored cancelled closures carry reason
      "cancelled" and no tool output or success claim.

PASS  SEC-INV-002 / commit-before-effect on restore
      Spawn does not resume the timer, model, tools, or
      expire-if-due while cancellation is set. CancelEffect and
      CancellationReconciled commit before any further dispatch.
      An overdue timer fires once through KernelInput::TimerFired
      after the wait is installed from the persisted due_at.

PASS  SEC-INV-003 / correlated outstanding identifier
      Cancel and reconcile use the committed EffectId. Interaction
      cancel reuses the existing interaction_id. Retry restore
      uses the same timer_effect_id / due_at / attempt. No TimerId
      and no ExecuteEffect for the interaction effect.

PASS  SEC-INV-004 / duplicates idempotent, conflicts fail closed
      Equal CancelRequested (same initiator and reason) is
      Idempotent. Equal TimerFired is UseRecorded. fired_at <
      due_at stays ConflictingSettlement. Late privileged
      completion after cancel won is fail-closed and audited.

PASS  SEC-INV-007 / bounded time and retries
      MonotonicDeadline::from_persisted clamps remaining wait to
      the persisted schedule interval. Backward wall jumps never
      extend an active wait (TimerDiagnostics.backward_clock_clamped).
      Already-due restore increments already_due and fires once.
      max_retries still binds on decide_retry. No polling loop.

PASS  SEC-INV-008 / identity not substituted
      Restore and cancel keep the original EffectId, attempt, and
      due_at. ExternalClock is host-injected wall time only; the
      kernel never reads ambient time.

PASS  TM-10 secondary
      Late conflicting privileged completion after cancel uses the
      existing rejection/audit path. Uncertainty suspends. No
      fabricated successful tool or model result.
