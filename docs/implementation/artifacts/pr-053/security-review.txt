  Guest SDK public surface (macros, catalog digest, size checks)

  plugin_instantiate_failed

  Graph: guest-sdk has no wasmtime / plugin-host / kernel / runtime;
  default SDK bundles have no guest-sdk; host has no guest-sdk
  ADR-011: no native dylib loader
  ADR-035: packages stay @0.0.4; crate version stays 0.0.3;
  MIGRATION.md documents a hypothetical @0.0.5 retarget only

Triggered controls: TM-06 primary (published FS-consuming guest stays
isolated T3; not finstack-ai-tools-filesystem), TM-07 (template and
calculator import only world-required host interfaces; sandbox
imports wasi:filesystem@0.2.12 and fails closed without grant+preopen),
SEC-INV-006 / 007 / 011 / 012, ADR-010, ADR-011, ADR-035.

PASS  TM-06 / trust labels
      PluginHost remains isolated Wasmtime (T3). In-process
      finstack-ai-wit adapters remain host-authority. The published
      filesystem sandbox is a T3 fixture over a granted preopen. It is
      not finstack-ai-tools-filesystem and is not a sandbox for
      in-process guests. WASM alone is not complete application-level
      safety. ExtensionDescriptor still uses trusted_in_process;
      isolation is a property of PluginHost.

PASS  TM-07 / deny-by-default WASI
      Calculator, context-provider, and templates do not import wasi:*.
      Sandbox instantiate without grant+preopen stays failed-closed.
      Linking wasi:io and wall-clock only when filesystem is
      resource-backed does not offer clock as a guest-facing grant and
      does not link sockets, HTTP, or CLI. Default host grants and
      default resource-limit numbers are unchanged. Sandbox and
      template manifests may raise max_instances for their own
      component; that is per-manifest, not a host default change.

PASS  ADR-010 / guest-authoring slice
      finstack-ai-guest-sdk is a native helper crate. Guests are not
      workspace members. Host loads bytes only. Lockfile discovery
      remains PR-054. G6 remains.

PASS  ADR-011 / no native dylib ABI
      No dylib loader, libloading, or native plugin path was added.

PASS  ADR-035 / experimental 0.x
      Packages stay @0.0.4. Crate version stays 0.0.3. @1.0.0
      generation remains blocked. G6 owns Implemented.

Residual already recorded:
  Linking wall-clock as a filesystem ABI dependency means a
  filesystem-granted guest could also import wasi:clocks/wall-clock.
  Calculator and templates do not. Do not treat this as a clock grant.
  Lockfile binding of bytes↔manifest, hostile conformance-suite
  completion, G6, and the 0.0.4 cut remain PR-054. This review does
  not claim that WASM alone is complete application-level safety.
