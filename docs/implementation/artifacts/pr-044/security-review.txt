PASS  TM-11 / unauthorized or replayed resolution
      Route requires locator identity (tenant_scope, session_id,
      lane_id, run_id), principal/policy/decision match, and a
      known interaction_id before any settlement. Unknown locator,
      unknown target, and authorization mismatch share one
      non-revealing IngressRejected after required audit.
      Response schema is validated on the kernel command.
      expires_at due at submitted_at becomes InteractionExpired
      before resolve. Denied or expired approval never opens the
      protected tool effect (A02). Grant requires
      last_interaction_terminal for the current cursor.

PASS  SEC-INV-003 / correlated outstanding identifier
      Request commits InteractionRequested with EffectRequested
      { kind: Interaction } under one interaction_id / effect_id.
      Settlement is valid only in AwaitingInteraction against that
      outstanding pair. List returns 0 or 1 pending request for
      the authenticated locator. No journal scan by global
      interaction ID. No ExecuteEffect for the interaction effect.

PASS  SEC-INV-004 / duplicates idempotent, conflicts audited
      Equal resolution_id plus normalized digest is Idempotent
      (A03). Conflicting or late resolution on a known target
      appends RecordExternalCommandRejected kind
      InteractionResolution, reason conflicting_or_invalid_resolution,
      and changes no run state. Unknown/unauthenticated attempts
      are audit-only.

PASS  TM-10 / TM-14 secondary
      Interaction settlement reuses the authenticated direct-locator
      pattern from ExternalCompletionRouter. Uncertainty on an
      unpaired projection suspends and does not fabricate a
      resolution. Cancel-during-suspended-interaction and the
      native timer matrix remain PR-045. Deadline recheck on
      resolve is in scope; the full race matrix is not.
