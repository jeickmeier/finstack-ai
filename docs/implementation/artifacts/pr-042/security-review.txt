PASS  TM-10 / spoofed or replayed external completion
      First-pass classification reads only committed KernelState.
      Settlement uses the original EffectId. Equal indexed completions
      are UseRecorded. Conflicting completion IDs, settlement
      fingerprints, or deferred handles fail closed and append
      RecordExternalCommandRejected with
      conflicting_or_invalid_completion. A02 never re-requests after
      a committed EffectCompleted / settlement-index hit. A05 proves
      equal deferred completion is idempotent and a conflicting
      handle or completion fails closed. Ingress still rejects
      host-supplied model-assistant decode.

PASS  SEC-INV-003 / correlated outstanding identifier
      ReconcileContext carries the committed locator, authorization,
      EffectId, attempt, deadline, and original_input_digest.
      Retry re-dispatches the same EffectId, ModelRequestId,
      canonical draft bytes, and input_digest (A03). Deferred
      completion stays under the original EffectId. AwaitingExternal
      NotStarted / RetrySafe / Unknown never re-request.

PASS  SEC-INV-004 / duplicates idempotent, conflicts audited
      Equal completion after an index hit is UseRecorded. Unequal
      completion or a different deferred handle submits
      RecordExternalCommandRejected and returns SuspendUncertain.
      No fabricated EffectCompleted is written on Unknown or
      NonRepeatable.

PASS  SEC-INV-008 / identity not substituted
      resume_request dispatches the committed seed only. The
      dispatcher validates the frozen draft against canonical bytes
      before request(). OpenAI-compatible reconcile is Unknown and
      idempotent_requests is false, so A04 suspends with
      model_reconciliation_unsupported and does not request().

PASS  TM-14 / late privileged completion and uncertainty
      Uncertainty suspends. NonRepeatable always suspends.
      Unknown without retry_allowed suspends. retry_allowed requires
      SafeToRetry or IdempotentWithKey and
      capabilities.idempotent_requests. AtMostOnce and Unknown
      retry safety are not retryable. Cancel-during-suspended-model
      remains PR-045. Deadline and cancellation continue to use the
      existing settlement rechecks; this PR does not add that matrix.
