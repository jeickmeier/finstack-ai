Triggered controls: Threat Model section 18 (secret-bearing
network adapter). Primary TM-04 / SEC-INV-005. Also SEC-INV-012
(minimal/default builds stay provider-free) and TM-05 (no
browser Anthropic key path).

PASS  TM-04 / SEC-INV-005 secret containment
      SecretString, Authentication, SecretHeader, and
      AnthropicConfig use redacted Debug. Provider Debug prints
      model names only. HTTP credentials and secret headers are
      built only inside the native client and require HTTPS;
      keyless loopback HTTP is explicit. URL userinfo, query, and
      fragment are rejected. Error constructors take static
      messages; response bodies, URLs, and header values are not
      interpolated. Canary
      `sk-ant-secret-canary-055` is absent from Debug and from
      the Python ConfigurationError path that rejects HTTP
      credentials. Recorded fixtures contain no credentials.
      Cache counters use namespaced Usage.extension_counters
      keys. Thinking signatures ride in OpaqueBlock media type
      `application/vnd.finstack.anthropic.thinking-signature`.
      No new kernel ContentBlock or Usage field. No secret enters
      a kernel record, runtime event, or provider descriptor.

PASS  TM-16 / SEC-INV-007 hostile stream bounds
      Named Anthropic SSE (`event:` + `data:`) has independent
      event and stream byte ceilings enforced before retained
      parse. Unknown event names and `error` events fail closed.
      `ping` is the only allowlisted no-op. Terminal is
      `message_stop`. The consumer channel is bounded (32).
      Cancellation races the read and returns
      `anthropic_cancelled`. Dropping the consumer aborts the
      owned task. HTTP 429 is retryable and does not expose the
      recorded body canary. Redirects are disabled. One
      reqwest::Client is reused.

PASS  SEC-INV-012 / default-graph posture
      Anthropic and OpenAI-compatible are trusted native leaves
      on the public runtime Model port. Direct dependencies are
      runtime + reqwest; no direct kernel, wasmtime, pyo3, or
      plugin-host edge. Kernel, runtime, and default SDK trees
      contain neither provider crate nor reqwest. finstack-ai-wit
      is clean. finstack-ai-native-examples retains the
      pre-existing rust-minimal OpenAI-compatible leaf and does
      not gain Anthropic. check-wasm FORBIDDEN_WASM includes
      both provider crates. No default SDK feature pulls a
      network provider. Python links both leaves into the one
      curated wheel; import still constructs no client.

PASS  TM-05 / no browser Anthropic key path
      No JS/WASM Anthropic adapter, no browser-embedded
      `x-api-key`, and no ANTHROPIC_API_KEY field was added to
      the wasm package. The wasm secret scan now also forbids
      `ANTHROPIC_API_KEY`. Ollama/local is a keyless
      EndpointKind::Ollama configuration of the existing
      compatible crate, not a third HTTP stack.

Architecture and residual-risk disposition

- ADR-023 remains the Chat Completions reference plus scripted
  semantic reference. Anthropic is an additional leaf. No new
  ADR. The Model trait is unchanged. No seventh port.
- Endpoint compatibility for Ollama is the existing quirks
  family. Live coverage stays an opt-in ignored smoke.
- Trusted host configuration can still direct requests to an
  arbitrary HTTP(S) endpoint; this is explicit native authority.
- Hosted OS matrices, independent review, cargo-deny, and
  gitleaks are not claimed.
- G7 remains Not ready. This review is not G7-D-*.
