PASS  Threat Model §8.3 handle-correlated bounds
      Every protocol message is versioned JSON. Control envelopes are
      rejected above 16 KiB. Transferred event-batch buffers are rejected
      above 256 KiB. Batch, ack, cancel, and backpressure messages carry
      agentId and runId. Uncorrelated or unknown handles are rejected.
      toJsonBytes() is copied into a fresh ArrayBuffer before transfer so
      wasm memory is not detached.

PASS  Terminate, unload, and cancel
      WorkerClient.terminate() cancels in-flight result waiters with
      agent_run_cancelled and session context when the run has started,
      then worker.terminate(). Page navigation drops main-thread waiters.
      Memory-store restart cannot resume. cancel() is explicit and
      idempotent. Dropping WorkerRun / aborting events() closes delivery
      only. Unexpected worker crash (other than the known wasm-bindgen
      abort-on-drop throw, which also occurs on the UI thread) maps to
      agent_run_runtime_failure.

PASS  Drop is not cancel
      Default lag policy is drop-progress. Transient batches may be
      dropped when the outbound queue is full. Durable and terminal
      batches are never dropped. droppedProgress is aggregated onto the
      next delivered batch and exposed on backpressure(). Disconnect and
      block-bounded are documented on WorkerConnectOptions.

PASS  Redaction and secrets
      Protocol errors reuse FinstackError codes. Durable diagnostics stay
      free of raw JS exception text. Secret scan of js/src, README,
      harness.html, worker-harness.html, and generated glue found no
      apiKey, OPENAI_API_KEY, or provider-token pattern. The OpenAI
      adapter still has no credential field. Fetch abort uses a detached
      local AbortController so wasm cancel does not attach the engine
      signal directly to fetch.

PASS  Trust class and persistence
      JS adapters remain trusted T2 and are constructed inside the worker
      factory. No MessagePort-bridged main-thread adapters. No
      SharedWorker, Service Worker, SharedArrayBuffer, or COOP/COEP.
      Default journal remains process-local Rust MemoryJournalStore.
      Worker restart cannot resume. IndexedDB remains PR-037.

PASS  No G4 / adapter flip / ADR Implemented
      DeferredBindingAdapter::wasm() remains Unavailable. ADR-031 stays
      Accepted / In progress / Partial. ADR-019 stays Partial. UI-thread
      Agent.create is unchanged and is not auto-wrapped in a Worker.
