PR-013 security and threat-model review
Date: 2026-08-09
Reviewed commit: aba26764a448f6b2691bfac62a0f36f865f61ed6
Reviewer: me@jeickmeier.com
Result: PASS for the implemented pure-kernel hardening scope

Scope reviewed

- Candidate-v1 deterministic decision/apply/replay semantics, strict serialized
  public-input decoding, deferred effects, lineage, typed interaction DTOs,
  cancellation/retry/timer races, limits, terminal integrity, and fuzz entry
  points.
- Threat Model TM-10, TM-11, TM-14, TM-15, TM-16 and SEC-INV-002,
  SEC-INV-003, SEC-INV-004, SEC-INV-007, SEC-INV-008, SEC-INV-009,
  SEC-INV-010, SEC-INV-011.

Control disposition

PASS - TM-10 / SEC-INV-003 and SEC-INV-004 external completion integrity
Equal duplicate completion identities are idempotent, conflicting reuse fails
closed, original effect/output-contract identity survives deferral, and corrupt
effect/session/lane/run substitutions are rejected atomically. Runtime router
authentication and durable external reconciliation remain later-phase work.

PASS - TM-11 typed interaction envelopes
Strict interaction DTO decoding enforces principal/authorization pairing,
unknown-field rejection, request/effect sibling rules, bounds, serialization,
and derived-event semantics. AwaitingInteraction routing and authorization
execution were not fabricated and remain PR-018/PR-044/PR-048 work.

PASS - TM-14 / SEC-INV-002 and SEC-INV-009 race and terminal integrity
Cancellation, reconciliation, retry, timer firing, duplicate completion, and
terminal race permutations preserve committed-journal precedence. A rejected
apply leaves state and state hash unchanged. before_finalize remains the last
behavior-changing kernel transition and terminals are immutable.

PASS - TM-15 / SEC-INV-008 lineage attenuation
Child depth, principal, tenant, deadline, budgets, ceilings, and propagation
cannot amplify parent authority. Serialized child acceptance re-enters the same
validation path. Actual runtime child dispatch and recovery remain later scope.

PASS - TM-16 / SEC-INV-007, SEC-INV-010, and SEC-INV-011 malformed input
Exact/one-over boundaries, unknown fields and variants, unsupported record,
event, state, trace and fixture versions, corrupt record order/identity/event
ordinals/fingerprints, and four JSON fuzz targets fail safely without panic.
Production and fuzz dependency graphs are checked separately; proptest and
libfuzzer do not enter the normal kernel consumer graph.

PASS - architecture and compatibility boundary
No runtime effect executor, port, I/O path, interaction router, production
registry, new public semantic variant, or golden-output change was introduced.
Native execution and compile-only wasm32 test portability passed at the reviewed
commit.

Residual later-PR obligations

- Hosted cross-platform CI and the manually dispatched long-fuzz campaign are
  required before PR-013 A03 and G1 can close.
- Runtime effect authentication/reconciliation, typed interaction routing,
  child dispatch, journal stores, protocol framing/CBOR, providers, WIT, and
  binding execution remain owned by later phases.
- ADR-025 through ADR-028 therefore retain Partial evidence; this review does
  not claim their later lifecycle work complete.
