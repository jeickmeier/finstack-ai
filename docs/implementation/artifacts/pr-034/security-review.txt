      facade wasm-host, and runtime wasm-host on wasm32-unknown-unknown

      production dependency.

PASS  Stable host diagnostics
      js_host_cancelled, js_host_failed, and js_host_result_invalid are
      frozen codes. Durable diagnostics omit raw JavaScript exception text.
      AbortError maps to Cancellation. CORS/network failures surface as
      js_host_failed.

PASS  Trust class and persistence
      JS adapters are trusted T2, the same class as Python callbacks. No new
      listener, worker, IndexedDB, or SQLite surface is added. HostJournalStore
      forces durable=false and rejects append/snapshot with
      js_host_store_prebeta.

PASS  Generated-glue and source secret scan
      check.py secrets over js/src, README, harness.html, and generated glue
      found no credential-field or provider-secret pattern. Generated glue
      contains no PEM material or credential helpers.

PASS  Target-correct port bounds
      Native host adapters remain Send + Sync. wasm32 wrappers store JS
      functions in Rc<RefCell<_>> and are not marked Send. No unsafe Send
      assertions were added.
