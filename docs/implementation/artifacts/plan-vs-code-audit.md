# Plan-versus-code audit

Scope: `docs/planning/04-finstack-ai-implementation-plan.md` (PR-001–PR-067, cross-phase §18/§20/§21/§22) plus the NFR/Engineering-Standards obligations it traces to, checked against the working tree. Every finding below survived an adversarial verification pass in which a second reviewer tried and failed to find the implementation.

Severity vocabulary: **missing** (no implementation), **partial** (one half of a conjunction delivered), **divergent** (shipped behaviour differs from the plan text, usually deliberately), **evidence-gap** (behaviour exists but the required proof does not), **stub** (code exists but is structurally unreachable), **doc-only** (satisfied by markdown alone).

## 1. Bottom line

The product surface of the plan is substantially implemented: the kernel, runtime, SDK, Python and WASM bindings, journal/durability, plugin host, remote protocol, and the extension leaves all exist as real, tested code, and the great majority of the 354 acceptance bullets are backed by executable tests. What is genuinely outstanding is not features but **enforcement and evidence**. Three clusters account for nearly every finding: (a) the CI/automation layer was deliberately reduced to a single `ubuntu-24.04` job (`.github/workflows/ci.yml:34`) and the architecture, schema-governance, secret-scanning, Miri, fuzz, wheel-matrix, release-smoke and docs gates were deleted (`.github/ci/README.md:56-65`), so a large set of "checks fail CI" acceptance bullets now have no executable check; (b) the NFR-PERF budget program measures but does not enforce — no workflow runs any benchmark, and 2 of 3 ratified size budgets are structurally unfailable (`tools/perf/check_size_budgets.py:43`); and (c) several documented registers now point at deleted tooling (`docs/implementation/exceptions-register.md:39` → nonexistent `tools/architecture/allowlist.toml`; 43 evidence rows cite `mise run` tasks that do not exist). Three items are **live regressions, not just gaps**: the browser journal known-answer test asserts 39 fixtures against a 40-fixture corpus and fails on the CI path (`bindings/finstack-ai-wasm/js/src/journal.test.ts:36`); `tools/docs/quickstarts.py` raises `FileNotFoundError` and `cargo package` fails for 17 crates because their `readme = "README.md"` targets were deleted; and `cargo clippy -p finstack-ai-runtime --no-default-features -- -D warnings` (and the documented `mise run runtime` task) is red at HEAD. Functionally, the one architecturally significant hole is that the `ContextProvider` port has no production driver, which the runtime documents itself (`crates/finstack-ai-runtime/src/exec/middleware_driver/mod.rs:111`) and which transitively makes the compaction leaf unable to land either of its outcomes.
