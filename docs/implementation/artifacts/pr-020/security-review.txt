Control disposition

PASS - SEC-INV-002/004/008/009 / TM-14 commit-before-effect and race safety
The manual-drive gate is reached only after an append receipt matches the frozen
request, the committed batch applies, durable-derived events publish, and the
effect's current authorization/deadline precondition passes. A blocked fixture
recovers the exact pending committed effect while the dispatcher count is zero.
A failed fourth append proves zero provider requests. Dropped permits/controllers
fail closed with stable post-commit faults; continued ambiguous acknowledgement,
receipt mismatch, replay/apply uncertainty, and repeated conflict do not dispatch.

PASS - SEC-INV-005/007 / TM-16/TM-17 bounds and non-semantic observation
Every Tokio channel, subscriber set, scheduler pending queue, model/tool result
path, and manual-drive queue has a validated finite bound. Tool execution also
requires global and per-tool semaphore permits. Slow-observer policy remains
explicit, isolated, and unable to alter semantic state. The new manual-drive
effect view contains only action kind and committed EffectId; it exposes no
provider payload, credential, or mutable kernel state.

PASS - SEC-INV-009/010/011 cleanup and observable failure
The sole RunTaskOwner still owns and joins all spawned work. Stress fixtures
prove 128 idle owners join gracefully, 24 end-to-end model runs leave no active
stream, tool shutdown leaves no child stream, and stalled observers do not delay
interactive delivery. Forced and owner-dropped paths remain bounded and
observable. Manual drive is explicit test control: it can intentionally pause a
run, but dropping its permit/controller unblocks with a fault and normal owner
shutdown retains its configured abort deadline.

PASS - SEC-INV-012 / TM-18 dependency and target containment
Manual drive compiles only with native-tokio; the selected browser-WASM graph is
unchanged and Tokio-free where required. The RSS probe exists only as a bench
target, invokes ps with a numeric current-process id, and is absent from
production dependencies. No new crate, network client, provider, database,
workflow engine, plugin host, dynamic loading, credential surface, or serialized
contract is introduced. Workspace Clippy, Rustdoc, architecture, supply-chain,
secret, release, packaging, minimal, and WASM checks pass.

PASS - feasible unsafe-free interpreter coverage
No unsafe block exists in kernel/runtime source. Pinned Miri passes representative
raw-JSON canonicalization, reducer semantic validation/apply, and deterministic
fingerprint paths. The deliberately multi-megabyte source-ceiling fixture makes
the complete 94-test interpreted suite impractical; it remains covered by normal
and aggregate tests. This limitation is recorded rather than presented as a full
Miri-suite pass.
