PASS  TM-12 / SEC-INV-010 journal integrity
      Append commits whole batches with protocol payload digests and
      envelope checksums over replay fields only (excludes committed_at
      and the checksum field). Load and scan call verify_chain before
      returning records; reordered, truncated, payload-modified, and
      wrong-head fixtures fail closed with explicit integrity codes
      before apply. Unknown versions, bignum tags 2/3, duplicate keys,
      indefinite lengths, and non-finite floats fail closed. JSON/JSONL
      is diagnostic only.

PASS  TM-16 / SEC-INV-007 bounded decode
      Declared lengths are checked before allocation. Envelope 8 MiB;
      batch checked sum of envelope lengths and 256 records (16 MiB);
      text/bytes 4 MiB; array 4096; map 256; nesting 32. Exact-limit
      fixtures accept; one-over-limit fixtures return
      canonical_limit_exceeded. Scan limit 0 is invalid; page max is
      256. Memory store health().durable stays false.

PASS  TM-10 compare-and-append identity
      append remains the one JournalStore compare-and-append. Exact
      batch_id and record-id reuse return the original receipt or
      Corruption. Post-commit AmbiguousAcknowledgement retry returns
      that receipt once; a concurrent new batch_id still conflicts.
      Decide / Agent.run do not emit the four new structural records.

PASS  TM-04 journal secret surface
      The codec and known-answer helpers hash and project typed
      records. They do not add a secret-bearing adapter, persist
      provider credentials, or change redaction rules. Metadata CAS
      never grants authority.

PASS  TM-18 new crate dependency
      ciborium 0.2.2 is the existing workspace pin. Production encode
      is the project wrapper; ciborium::ser::into_writer is not treated
      as canonical. mise.toml has no supply-chain task and deny.toml
      is absent; this review records the pin and cargo tree, not a
      cargo-deny pass. Runtime and SDK production graphs stay
      protocol-free.
