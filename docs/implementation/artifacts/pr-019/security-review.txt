Control disposition

PASS - SEC-INV-002 / TM-14 durable intent controls cancellation and timer work
The kernel's committed post-commit actions remain the only path to model, tool,
or timer dispatch. Cancellation intent is committed before the runtime signals an
effect-local descendant token. RetryScheduled and its timer EffectRequested record
are committed before the timer dispatcher installs a wait. Recovery reconstructs
the pending timer seed from committed records; process memory never invents timer
intent or an attempt number.

PASS - SEC-INV-004/008/009 / TM-14 late races fail closed
Cancellation reconciliation uses the exact committed request ID and outstanding
EffectId. A post-cancellation driver terminal is classified only as completed or
cancelled evidence and cannot resume ordinary progress. The kernel remains the
source of source-ordered synthetic tool closures and terminal precedence. Model and
tool deadlines are checked before child-task creation and again before settlement;
an overdue model fixture proves zero provider calls. Timer firing carries the exact
scheduled effect ID and due time, and kernel duplicate/conflict rules remain intact.

PASS - SEC-INV-007 / TM-16 time, retries, queues, and shutdown are bounded
All new job and result paths reuse configured bounded channels. A persisted timer's
original maximum is derived from its committed scheduling interval; backward wall
movement is clamped to that maximum. Retry jitter is supplied outside the pure
kernel and rejected when it exceeds its declared maximum or overflows. Cancellation
grace uses the existing non-zero shutdown deadline. Forced abort counts and timer
anomaly counters are numeric diagnostics without payload content.

PASS - SEC-INV-010/011 explicit clock and recovery failures are observable
Invalid persisted intervals, clock-source failures, monotonic overflow, unknown
allocation kinds, timer queue closure, and timer registry faults produce stable
runtime errors rather than guessed state. Already-due and backward-clamped timer
conversions increment safe process-local diagnostics. A restart fixture proves one
firing, one persisted attempt, cleared pending state, and no duplicate wakeup.

PASS - SEC-INV-012 / TM-18 target and dependency boundaries remain narrow
The timer and Tokio task modules compile only with `native-tokio`. Minimal/default
checks and wasm32 production graphs remain green and Tokio-free where required.
No provider, network client, durable database, workflow engine, plugin engine,
dynamic loading, new dependency, credential surface, or external publication is
introduced. Workspace Clippy, architecture, supply-chain, secret, release-smoke,
and packaging checks pass.
