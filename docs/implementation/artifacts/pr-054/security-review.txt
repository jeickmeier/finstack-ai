PASS  TM-08 / lockfile binding
      Runtime startup reads one local JSON lockfile. It does not
      walk a plugin directory and does not fetch. A path with
      ://, a scheme, or .. is plugin_lock_invalid. Duplicate
      identity fails at resolve even when one entry is disabled.
      load_locked of a disabled entry is plugin_lock_disabled.
      Component SHA-256 or parsed manifest.digest mismatch is
      plugin_lock_digest_mismatch. The installer copies
      manifest.digest and hashes component bytes; it does not
      import the host or open a network socket. ResolvedAgentLock
      is not reused.

PASS  TM-07 / hostile suite
      conformance_tests.rs names every G6 row. Lifecycle timeout,
      malformed manifest, permission denial, ungranted WASI,
      trap, fuel, unsigned/untrusted signature, cancellation,
      oversized args-json before guest allocation, calculator
      loaded as context-plugin, lockfile duplicate/substitution/
      URL, disabled sandbox absent from load_enabled, and cache
      ABI miss are all present. No new WASI grant or wasi:http
      linking was added to write these rows.

PASS  TM-06 / trust labels
      PluginHost remains isolated Wasmtime (T3). In-process
      finstack-ai-wit adapters remain host-authority. Published
      references stay T3 guests, not the trusted native
      calculator or filesystem batteries. WASM alone is not
      complete application-level safety.
      ExtensionDescriptor still uses trusted_in_process;
      isolation is a property of PluginHost.

PASS  ADR-010 / optional isolation
      Wasmtime stays in the plugins/ host leaf. Default bundles
      do not depend on it. load_enabled is the discovery surface.

PASS  ADR-011 / no native dylib ABI
      No dylib loader, libloading, or native plugin path was added.

PASS  ADR-035 / experimental 0.x
      Packages stay @0.0.4. Workspace crate version is staged
      unpublished 0.0.4. @1.0.0 generation remains blocked.
      G6 owns Implemented.
