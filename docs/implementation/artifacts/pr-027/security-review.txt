Reviewed controls

- TM-18: PyO3 and maturin are exactly pinned; the PEP 517 build dependency is

  pinned; cargo-deny, actionlint, archive inspection, exact hashes, secret scan,
  and the secret-scan canary pass.
- SEC-INV-005 / TM-04: import and `health()` are credential-free. A subprocess
  audit observes no Python socket events or new threads, and the Rust module
  does not create a Tokio runtime or provider client at import.
- TM-06: the native module is the approved trusted in-process binding path and
  reuses the Rust SDK/provider implementation. It does not introduce a native
  dylib plugin ABI or a second semantic engine.
- Archive safety: wheel/sdist checks reject absolute/traversal paths, links,
  private build paths, generated bytecode, missing licenses/stubs, classic
  abi3 names, duplicate artifacts, metadata drift, and oversized wheels.
- Free-threaded safety: the module declares `gil_used = false`; the dedicated
  3.14t smoke requires a disabled GIL and exercises 512 concurrent native
  `health()` calls.

- The OpenAI-compatible provider is linked but no client is created and no live
  provider or credential path is exercised.
- Deterministic SBOM/provenance staging and publication controls remain PR-032.
