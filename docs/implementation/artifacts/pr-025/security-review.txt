TM-03 / filesystem escape
- The host supplies one explicit root. On Unix the constructor opens and keeps
  a directory descriptor with DIRECTORY, NOFOLLOW, and CLOEXEC.
- Model paths must be bounded relative UTF-8 component lists. Absolute paths,
  empty file paths, dot/parent components, duplicate separators, backslashes,
  NUL, excessive length, and excessive depth fail before filesystem I/O.
- Each intermediate component is opened relative to the preceding directory
  descriptor with DIRECTORY|NOFOLLOW. Final reads/writes/edits use the opened
  parent descriptor and NOFOLLOW; opened objects are checked as regular files.
- Read/write/edit handles use NONBLOCK so special files cannot cause an
  unbounded blocking open. Recursive traversal is bounded and skips symlinks.
- Deterministic hooks prove a symlink swap before final open is rejected and a
  rename/symlink replacement after open still reads the originally opened
  object. Outside content uses a canary and is absent from results/errors.
- Default protected components are .git, .env, and .ssh. Host-supplied plain
  component or bounded glob patterns are validated once at construction.

SEC-INV-001 / content is not authority
- File content, search matches, glob results, and artifact attributes cannot
  change root authority or protected-path policy. No path or content is
  evaluated as a command. PR-025 includes no shell surface.

SEC-INV-007 / bounds
- File bytes, visited entries, search matches, recursion depth, paths,
  components, patterns, query bytes, previews, inline JSON, and artifact bytes
  have explicit ceilings. One byte above a file/result ceiling fails rather
  than truncating or creating an untracked spill file.
- Cancellation is checked before operations, during walks/searches, and before
  mutation after edit preparation. Runtime deadline/cancellation ownership is
  unchanged.

SEC-INV-008 / identity and scope
- Every public tool call validates the committed tool ID/name and the
  authenticated principal tenant against the exact operation locator.
- Oversized output derives ArtifactScope from the committed locator's tenant,
  session, and run and records the committed EffectId as non-authoritative
  metadata. stage_required_artifact verifies scope/content/metadata exactly.

SEC-INV-012 / optional privileged batteries
- Both packages are leaf workspace members depending on public runtime
  contracts. Focused graph checks and the architecture gate prove calculator,
  filesystem, and rustix do not enter kernel or runtime normal graphs.
- Rustix 1.1.4 was already present in the lock graph; direct use enables only
  alloc/fs/std. Cargo-deny passes without a policy expansion.

Residual boundaries and exclusions
- This is trusted native in-process code, not an OS sandbox. Host root choice,
  host hardening, directory ownership, hard links/mounts already visible under
  that opened root, and tenant deployment isolation remain application duties.
- The safe implementation is Unix-specific in this candidate. Non-Unix
  construction fails closed; no local Windows cross-target or hosted matrix was
  available. Browser-WASM is not a target for this native leaf.
- No shell, Git, browser, recursive delete, ambient environment/secret access,
  tracked or untracked spill file, network effect, or later PR-056 hardening is
  present.
