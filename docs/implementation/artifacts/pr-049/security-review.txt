PASS  TM-07 / explicit linked capabilities (PR-049 slice)
      toolset-plugin imports only logging.log and blobs.read. Linking
      them is documented as not ambient WASI, filesystem, network,
      clock, environment, or secret access. The world exports only
      list-tools and call. No nested-agent, session, run, or lineage
      operations exist. There is no Wasmtime instantiate in this PR,
      so sandbox escape via a component instance is not yet in scope;
      the leaf cannot load a component.

PASS  TM-06 / trust labels
      README and COMPATIBILITY.md label the crate experimental @0.x
      and in-process. The reference toolset is a trusted Rust guest
      impl, not an isolated component. Native extensions remain under
      extensions/. plugins/finstack-ai-plugin-host stays README-only.

PASS  TM-16 / bounded decode
      args-json, catalog JSON, and schemas use the 1 MiB RawJson
      ceiling; metadata uses 64 KiB; blob reads and generic strings
      use 4 MiB. Declared blob max-bytes is rejected before the host
      allocates an output buffer. max-result-bytes == 0 fails
      registration. Guest catalog digest is verified, not trusted.

PASS  ADR-011 / no native dylib ABI
      No dylib loader, libloading, or native plugin path was added.
      Untrusted isolation remains the later Wasmtime host.

PASS  ADR-035 / experimental 0.x
      Packages are @0.0.4 only. generate.py fails on @1.0.0. Workspace
      crate version stays 0.0.3. Coarse one-shot list-tools/call; no
      component resources or progress streams.
