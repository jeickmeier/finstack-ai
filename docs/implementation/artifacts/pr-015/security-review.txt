Control disposition

PASS - TM-02 tool-call integrity within PR-015 scope
Tool-call fragments carry provider indexes but no framework IDs. First
appearance fixes source order; later names may fill but cannot mutate; strict
JSON arguments must complete before a successful terminal; streamed calls must
equal the final normalized response. The runtime allocates ToolCallId values
only after complete validation. ToolSpec is data-only: PR-015 performs no schema
compilation, authorization, scheduling, or execution.

PASS - SEC-INV-002 and TM-14 commit, cancellation, and deadline ordering
The coordinator first obtains a valid pure kernel decision, validates the exact
canonical ModelRequestDraft and estimator result, appends and applies
EffectRequested, then rechecks the committed outstanding effect, cancellation,
deadline, and committed batch immediately before bounded enqueue. A failed
append executes no model. One effect-local signal is registered per active
effect; CancelEffect targets only that signal. If completion wins the active-map
race, cancellation is idempotent and the single run worker discards the late
result from committed state. Results observed after the committed deadline are
settled as failure and cannot create an assistant message or completion identity.

PASS - TM-16 / SEC-INV-007 resource bounds and cleanup
Request bytes, token estimates, output limits, profile arithmetic, model job and
result queues, stream item count, aggregate bytes, text, reasoning, tool-call
count, usage counters, provider events, errors, and canonical JSON are bounded.
The driver owns at most one task per active effect. Deterministic gate tests
prove cancellation acknowledgement, consumer-drop cleanup, normal shutdown,
and forced abort after the configured grace deadline, each with zero active
scripted streams. Locks guard small registries and are not held across awaits.

PASS - TM-04 / SEC-INV-005 / SEC-INV-011 redaction and authority separation
The committed ModelRequestDraft has no typed runtime effect, authorization,
credential, or cancellation fields; the runtime does not inject those values
into its messages or provider settings. Effect identity, authorized principal,
and cancellation are injected only into the post-commit ModelCallContext.
Application-supplied prompt/settings data remains subject to the existing
secret-reference policy. Model errors expose only bounded safe messages and
Metadata. Text, reasoning, and explicit heartbeat progress become Confidential
transient RunEvents; opaque provider events remain driver-local. No new
observer/export/event-subscription surface is introduced.

PASS - TM-18 / SEC-INV-012 dependency and target boundary
The only new target-portable stream dependency is futures-core. Tokio remains
optional behind native-tokio; runtime defaults remain empty; the selected WASM
graph and the separate default-feature-free leaf compile without Tokio. No
provider, network, filesystem, secret, telemetry, executable tool, or persistent
store battery is added.
