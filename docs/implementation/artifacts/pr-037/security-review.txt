PR-037 binding-safety review (IndexedDB persistence, TM-05 / TM-20 / §8.3 / §8.6)
Date: 2026-08-13

Reviewer: me@jeickmeier.com
Decision: Pass; new same-origin persistence surface is a trusted T2 host
adapter, not a kernel port. No threat-model rewrite. No §6.3 ADR trigger.
npm publication remains excluded.

Scope reviewed:
  HostJournalStore append/load/writeSnapshot JSON proxy
  Agent.create({ store }) opt-in and Agent.inspectSession
  IndexedDB schema v1, CAS/idempotency, integrity failures, blob ceilings
  Worker inspect protocol (inspect / inspected)
  examples/browser-minimal public imports and deletion API
  tools/wasm_package/check.py secret roots (js/src, READMEs, example HTML/TS)
  health().durable remains false

PASS  TM-05 origin-scoped host persistence
      IndexedDB is constructed inside the Dedicated Worker. The UI talks
      only through connectWorker. No IDB handle is posted across workers.
      Default Agent.create stays memory-backed. Persistence is opt-in via
      Agent.create({ store }). Database name defaults to
      finstack-ai-experimental and is origin-scoped.

PASS  TM-20 / ADR-036 artifact boundary
      createIndexedDbArtifactStore implements HostArtifactStore stagePut/get
      with maxBlobBytes and maxBlobs ceilings. Uncorrelated gets fail with
      artifact_uncorrelated. No seventh kernel port. NativeAgentBuilder is
      unchanged. PR-056 remains for later adapters.

PASS  Threat Model §8.3 handle-correlated bounds
      Worker inspect carries sessionId only. Store objects stay in the
      worker. Size-bound every journal/artifact write before put. Schema
      version mismatch and unparseable batch JSON fail Integrity
      (journal_schema_unsupported / journal_record_corrupt).

PASS  Threat Model §8.6 deletion and inspect≠continue
      deleteIndexedDbStores is the documented deletion API. Deleting the
      database discards inspect history and is not run cancellation.
      Agent.inspectSession calls CommitCoordinator::recover and returns a
      provisional snapshot. There is no start({ sessionId }) continue path.
      A new memory-backed worker still cannot resume (PR-036 nonclaim).

PASS  Drop is not cancel
      Unchanged from PR-036. Dropping a Run or WorkerRun detaches
      observation only. Page unload may map to agent_run_cancelled when
      the protocol can flush. A02 documents in_progress or cancelled as
      valid provisional inspect phases. This is not the PR-048 crash-prefix
      matrix.

PASS  Redaction and secrets
      Secret scan of js/src, package README, harness HTML, generated glue,
      examples/browser-minimal, and examples/README.md found no apiKey,
      OPENAI_API_KEY, or provider-token pattern. The optional OpenAI
      adapter path still has no credential field. Durable diagnostics stay
      free of raw host exception text. health().detail is
      js_indexeddb_experimental.

PASS  Trust class and durability nonclaim
      JS adapters remain trusted T2 on the owning worker/local executor.
      No Service Worker, SharedWorker, SharedArrayBuffer, or COOP/COEP.
      health().durable stays false. Reload survival is inspect, not
      NFR-REL-001 crash durability. Encoding is transitional JSON.

PASS  No G4 / adapter flip / ADR Implemented
      DeferredBindingAdapter::wasm() remains Unavailable. ADR-019 and
      ADR-031 stay Accepted / In progress / Partial. ADR-036 stays Partial
      with IndexedDB artifact-adapter evidence added; PR-056 remains.
