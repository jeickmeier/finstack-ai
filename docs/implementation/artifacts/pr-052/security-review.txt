PASS  TM-07 / deny-by-default WASI and resource limits
      Ungranted wasi:filesystem / wasi:sockets / wasi:cli / wasi:http
      imports fail instantiate as plugin_instantiate_failed. A
      permission name is not a linked capability. filesystem links
      only with a concrete preopen; network links only with the
      explicit socket flag; http is never blanket-linked (no
      wasmtime-wasi-http in this PR). Fuel and StoreLimits exhaustion
      map to plugin_resource_limit without taking down the host.
      Deadline/cancel remain plugin_lifecycle_timeout. Secrets cannot
      be offered (no provider).

PASS  TM-08 / signature policy and trust roots
      Signed payload is the existing PR-050 canonical
      {identity, version, worlds} bytes. Algorithm lock is ed25519.
      Strict rejects unsigned and unknown/wrong keys as
      plugin_signature_untrusted. Permissive keeps unsigned-OK;
      present-but-bad still fails. No component-bytes signing and no
      registry discovery. Manifest digest remains host-computed;
      component-bytes digest remains the compile-cache identity.

PASS  TM-06 / trust labels
      PluginHost and adapters stay isolated Wasmtime (T3).
      finstack-ai-wit in-process adapters still inherit host
      authority and are not a sandbox. Adding wasmtime-wasi does not
      make the in-process path a sandbox. ExtensionDescriptor still
      uses trusted_in_process; isolation is a property of PluginHost.
      Default SDK bundles do not depend on the host.

PASS  ADR-010 / optional isolation leaf
      wasmtime and wasmtime-wasi live only in
      plugins/finstack-ai-plugin-host. This is the WASI/limits/
      signature slice. Lockfile discovery remains PR-054. G6 remains.

PASS  ADR-011 / no native dylib ABI
      No dylib loader, libloading, or native plugin path was added.

PASS  ADR-035 / experimental 0.x
      Packages stay @0.0.4. Crate version stays 0.0.3. @1.0.0
      generation remains blocked. G6 owns Implemented.
