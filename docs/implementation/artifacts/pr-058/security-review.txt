Triggered controls: Threat Model section 18 (network listener,
protocol parser). Primary TM-09. Also TM-10 / TM-11 (command
auth, idempotency), TM-16 (pre-allocation limits), TM-19
(locator/tenant), TM-20 (no store-private leak).

PASS  TM-09 protocol separation
      Remote and process share only the 4-byte length prefix and
      family-tagged envelope. Process handshake kinds use
      process_* names. A process hello does not decode as a
      remote session command. WIT worlds are unchanged @0.0.4.

PASS  TM-16 pre-allocation limits
      decode_frame_len rejects length > 16 KiB before the
      payload buffer is allocated. Post-auth ceiling is 256 KiB
      and is also checked before allocation. The 8 MiB journal
      envelope is not used as the pre-auth cap.

PASS  TM-10 / TM-11 auth and idempotency
      Only hello/auth/close are parsed pre-auth. No session
      lookup occurs before AuthResult. Bearer tokens are
      rejected on plaintext TCP. Commands carry UUIDv7 id,
      locator, tenant scope, and a domain-separated digest.
      Equal id+digest replays the receipt; conflicting reuse
      fails closed and is audited.

PASS  TM-19 locator / tenant
      Unknown session and tenant mismatch both surface as
      unknown_locator. A second writer is busy without
      confirming another tenant's session. Audit events carry
      locator/command digests only.

PASS  TM-20 no store-private leak
      Socket DTOs are RemoteSnapshot, RemoteEventView, and
      RemoteCommand. A public Session projects only its
      session_id string. No rusqlite types or journal page
      layouts cross the socket.

PASS  listen / TLS floor
      Non-loopback plaintext fails validate() with
      server_listen_invalid. TLS binds require a TLS 1.3-only
      rustls ServerConfig. rustls lives only in
      finstack-ai-server.

Residual: hosted matrix / cargo-deny / gitleaks not claimed.
No public TLS certificate was exercised. ADR-014 / ADR-021
close at integration. No G7-D.
