PASS  TM-10 / spoofed or replayed external completion
      First-pass classification reads only committed KernelState.
      Settlement uses the original EffectId. Equal indexed completions
      are UseRecorded. Conflicting completion IDs, settlement
      fingerprints, or deferred handles fail closed and append
      RecordExternalCommandRejected with
      conflicting_or_invalid_completion. A02 never re-calls after a
      committed ToolCallSettled / settlement-index hit. A05 proves
      equal deferred completion is idempotent and a conflicting
      handle fails closed. External Completed reuses
      allocate_tool_settlement IDs and omits assistant_message.

PASS  SEC-INV-003 / correlated outstanding identifier
      ReconcileContext carries the committed locator, authorization,
      EffectId, attempt, deadline, and original_input_digest.
      Retry re-dispatches the same EffectId, ToolCallId, ToolBatchId,
      and frozen ValidatedToolCall (A02). Deferred completion stays
      under the original EffectId. AwaitingExternal
      NotStarted / RetrySafe / Unknown never re-call.

PASS  SEC-INV-004 / duplicates idempotent, conflicts audited
      Equal completion after an index hit is UseRecorded. A different
      deferred handle submits RecordExternalCommandRejected and
      returns SuspendUncertain. No fabricated successful
      ToolCallSettled is written on Unknown or NonRepeatable.

PASS  SEC-INV-008 / identity not substituted
      resume_call dispatches the committed seed only. The dispatcher
      validates the frozen ValidatedToolCall against the catalog
      before call(). Calculator and filesystem reconcile stay
      Unknown. retry_allowed requires SafeToRetry or
      IdempotentWithKey and ReadOnly or IdempotentWrite.
      NonIdempotentWrite / AtMostOnce suspend with
      tool_reconciliation_unsupported and do not call().

PASS  TM-14 / late privileged completion and uncertainty
      Uncertainty suspends. NonRepeatable always suspends.
      Unknown without retry_allowed suspends. ToolFailurePolicy is
      not an uncertainty escape hatch. Cancel-during-suspended-tool
      remains PR-045. Deadline and cancellation continue to use the
      existing settlement rechecks; this PR does not add that matrix.
