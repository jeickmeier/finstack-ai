PASS  TM-12 / journal, snapshot, and prune
      Prefix delete requires a snapshot and a batch-aligned
      last_sequence. Records/batches below the snapshot sequence
      are removed; the boundary record stays so checksum_at can
      verify the snapshot. verify_chain_from seeds a truncated
      chain. Corrupt snapshots are discarded. Head sequence and
      head checksum are unchanged by prune. Outstanding effects
      and settlement tombstones are counted from the decoded
      snapshot KernelState, not a second index.

PASS  TM-10 / TM-14 / duplicate completion and cancel
      Equal external completion after restart is idempotent.
      Conflicting duplicates fail closed and leave the run
      unchanged. Post-horizon ingress is expired_locator with
      UnknownLocator audit; it does not claim historical
      idempotency. Cancel fan-out remains at-least-once plus
      idempotent CancelRequested.

PASS  TM-11 / interaction restart
      I1–I4 restore AwaitingInteraction, settled classification,
      expired terminal, and cancel-without-fabricated-tool-success.
      Session::open does not respawn parked runs. Lane inspect
      uses walk_conversation so a pending tool call is not
      reported as conversation corruption.

PASS  TM-15 / lineage and lanes
      L1–L3 keep one mapped UUIDv7 child. N1–N4 reconstruct lanes
      and busy-lane after SessionRuntime::open. RemoteChildSession
      stays vocabulary-only.

PASS  TM-21 / compaction artifacts
      Recorded outcomes replay without re-summarizing. Required
      ArtifactRef content is digest-checked; corrupt required
      content is artifact_integrity_failure. Disposable
      RecomputeSafe checkpoints may rebuild.

PASS  SEC-INV-008 / identity not substituted
      Metadata never grants authority (W5). Cross-scope recovery
      still uses tenant_scope + session_id on Session::open.
      Host ExternalIdentityMap remains host-owned and is not
      journaled.

PASS  SEC-INV-004 / SEC-INV-010
      Unknown sqlite user_version fails closed. Restore refuses
      dest-exists and orphan sidecars. Import refuses a non-empty
      session. Journal v1 family count stays 40. IndexedDB does
      not claim durable=true.
