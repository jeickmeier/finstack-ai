Control disposition

PASS - SEC-INV-007 / resource bounds
Every PR-011 counter has an explicit maximum and below/exact/above tests.
All aggregation uses checked arithmetic. Cost and extension-counter overflow
fail terminally without wrap, LimitReached fabrication, or fabricated usage.
Configured parallelism is rejected at kernel plan admission.

PASS - TM-14 / cancellation and deadline races
Cancellation intent and authorization are validated before cancellation can
change state; committed-order precedence is explicit. Outstanding effects are
reconciled incrementally, duplicate/conflicting observations are indexed,
uncertainty suspends, and cancelled closures cannot assert tool success or
tool-produced output. Tool closures finalize in assistant source order.

PASS - TM-15 / child attenuation and propagation
Propagation uses the persisted RunPropagationPolicy and normalized child
authorization decision. Cascade is deterministic. DetachOnlyIfPreauthorized
detaches only when the accepted decision reference carries explicit detach
authorization; otherwise cancellation propagates. No transient application
state is treated as authority.

PASS - SEC-INV-002, 004, 008, 009, 010, 011
The reducer remains synchronous and I/O-free; it emits effects only after the
records that authorize them. Equal retries/cancellations/reconciliations are
idempotent, conflicts fail closed, identifiers and lineage are checked,
terminal states are immutable, impossible state is rejected, and durable
records retain policy/reason/decision references without secret material.

PASS - architecture and supply-chain review
No primary port, dependency, runtime privilege, secret surface, host callback,
network path, filesystem path, executor, or dynamic-loading capability was
added. Aggregate architecture, supply-chain, secret-scan, and WASM checks pass.

- Actual authenticated child dispatch and cross-run fan-out remain runtime/SDK

These are declared exclusions, not exceptions to PR-011 acceptance.
