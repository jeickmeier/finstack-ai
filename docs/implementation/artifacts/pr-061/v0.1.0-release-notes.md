# v0.1.0 public preview

Tagged lockstep public-preview cut. G7 passed via
`G7-D-public-preview-f7c7e70b9e04`.

This release is a **git tag**, not a crates.io / PyPI / npm publication.
Consume the tree from tag `v0.1.0`. Experimental WIT package names stay
`finstack:ai-*@0.0.4`.

## Compatibility

See [`preview-compatibility-policy.md`](../../preview-compatibility-policy.md).
This is not a 1.0 SemVer guarantee.

## Install from the tag

```toml
finstack-ai = { git = "https://github.com/jeickmeier/finstack-ai", tag = "v0.1.0" }
```

Python and `@finstack/ai` remain path / staged-tarball installs until
registry credentials exist.

## Known limitations

- Experimental WIT `@0.0.4`
- Experimental IndexedDB (non-durable, inspect-not-continue)
- Delivery is at-least-once (ADR-013)
- Live provider smokes stay `#[ignore]`
- No marketplace, native dylib ABI, or 1.0 freeze
