PASS  TM-08 / manifest identity and ABI
      Identity must be a namespaced finstack.plugin.* ComponentId.
      Version must be experimental 0.0.4; 1.0.0 and @1.0.0 fail.
      Worlds are a non-empty subset of {toolset-plugin, context-plugin};
      middleware, agent, and other undeclared worlds fail. Permissions
      are a subset of {logging, blobs}; http/filesystem/network/secrets/
      clock/random fail until PR-052. Host computes the in-process
      digest over canonical {identity, version, worlds} and rejects
      mismatch. Optional signature metadata may be omitted; present
      but empty/malformed fields fail. Trust-root verify is PR-052.
      Duplicate identities fail closed.

PASS  TM-07 / explicit linked capabilities
      context-plugin imports only logging.log and blobs.read and
      exports only context-provider / collect. No initialize, health,
      shutdown, warmup, or nested-agent WIT exports exist. item-json
      keys interaction, deferral, agent, session, run, lineage,
      suspend, and approval fail as plugin_private_suspension.

PASS  TM-01 / no self-elevation
      trusted_application is accepted only when the resolved
      ContextProviderDescriptor.trusted_application_instructions flag
      is true. derived_summary must stay untrusted. The reference
      guest uses untrusted quoted_source and reference items.

PASS  TM-06 / trust labels
      README and COMPATIBILITY.md label the crate experimental @0.x
      and in-process. In-process guests inherit host authority and
      are labeled as such. Native extensions remain under extensions/.
      plugins/finstack-ai-plugin-host stays README-only.

PASS  TM-16 / bounded decode
      request-json, item-json, configuration_schema, and manifest
      JSON use the 1 MiB RawJson ceiling and reject before allocation.
      Blob declared lengths use the 4 MiB string ceiling. max-items
      == 0 or above SEMANTIC_ARRAY_MAX_ITEMS fails. Plugin overflow
      policy is host-owned Reject.

PASS  ADR-011 / no native dylib ABI
      No dylib loader, libloading, or native plugin path was added.

PASS  ADR-035 / experimental 0.x
      Packages stay @0.0.4. Crate version stays 0.0.3. @1.0.0
      generation remains blocked. Coarse one-shot collect; no
      component resources or progress streams. G6 owns Implemented.
