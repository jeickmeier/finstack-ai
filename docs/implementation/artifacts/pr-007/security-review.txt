TM-16 (oversized / malicious content parsing):
- Text/opaque-byte ceilings enforced at 4 MiB with source-aware escaped-string
  length validation before materializing semantic strings.
- Content arrays capped at 4,096 items with bounded visitors and capacity hints.
- Labels (blob id/media_type/name, tool_name, model refs) capped at 256 bytes,
  non-empty, NUL-rejected.
- Nested RawJson fields preserve source spans and duplicate-key rejection instead
  of passing through lossy serde_json::Value buffering.
- Unknown fields, inline media payloads, conflicting opaque payload fields, and
  unknown ContentBlock kinds are rejected.
- Nested tool-call/tool-result kinds are rejected before descending into their
  payload; invalid role/block combinations are rejected.
- Non-human opaque bytes remain byte strings rather than hexadecimal text.
- Control-change disposition: implements planned PR-007 parser/limit controls;
  no Threat Model text change required beyond existing TM-16 row.

TM-20 / ADR-036 (blob reference scope):
- BlobRef is opaque metadata (id, media_type, length, optional digest/name).
- No metadata authority field on BlobRef; ArtifactRef remains the durable
  metadata wrapper.
- Kernel never dereferences blobs; no seventh port; no store implementation.
- Large media serializes as a small reference (fixture max_serialized_bytes=200
  with declared length 50_000_000).
- Control-change disposition: no control change; verifies ADR-036 / TM-20.

SEC-INV-001 / SEC-INV-005 / SEC-INV-007:
- Content remains data, not authority.
- No secrets introduced in fixtures, metadata, or errors.
- Bounds checked before retaining content collections and strings.
