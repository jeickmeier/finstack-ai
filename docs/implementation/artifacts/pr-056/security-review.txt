(artifact spill), SEC-INV-001/007/008/012/013.

PASS  TM-03 / SEC-INV-001 / SEC-INV-008 shell and filesystem
      Shell is argv-only, deny-by-default, empty host
      environment plus a documented locale pair, optional
      no-follow cwd via rustix fchdir in a documented child
      pre_exec, deadline/cancellation timeout, and a hard
      stdout+stderr cap that fails shell_limit_exceeded or
      stages through ArtifactStore. No /bin/sh -c, no PATH
      search unless the policy opts in, no landlock/bubblewrap
      /seatbelt/libloading. Filesystem keeps PR-025
      handle-relative no-follow and adds an env-leakage row:
      .env / .ssh reads are denied, search does not return
      protected bytes, and public reads contain no KEY=VALUE
      dump from std::env::vars.

PASS  TM-01 / SEC-INV-013 repository and memory as data
      Repository items are QuotedSource + Untrusted +
      external:true with file provenance. Default allowlist is
      AGENTS.md, README.md, and .finstack/instructions.md.
      trusted_application_instructions stays false. Memory
      writes go through stage_required_artifact; collect is
      keyword/exact-id only. Tenant-scope mismatch fails
      closed. No embedding model, ANN, or network fetch.

PASS  TM-20 artifact spill
      Oversized shell JSON and memory bodies use the existing
      scoped ArtifactStore contract. Compaction large-tool-
      output truncates model-visible tool-result text and keeps
      call/result pairing; it does not create a second
      untracked spill file.

PASS  TM-21 / SEC-INV-007 compaction integrity
      One ContextCompactor at BeforeModel. Sliding-window and
      large-tool-output complete as CompactContext.
      validate_compaction_result plus
      check_compaction_conformance prove canonical-history
      immutability, protected-byte identity, tool-pair
      atomicity, hard-budget failure, and checkpoint
      invalidation. Summarize returns RequestCompactionModel
      with explicit model, budget scope, source sensitivity,
      and residency digest; resume cannot emit another
      RequestCompactionModel. Unauthorized secondary model
      fails with COMPACTION_MODEL_NOT_AUTHORIZED before
      dispatch. The leaf has no Model handle.

PASS  SEC-INV-012 / default-graph posture
      Kernel, runtime, default SDK, no-default SDK, wit, and
      wasm-host graphs contain none of the new privileged
      leaves. check-wasm FORBIDDEN_WASM now includes shell,
      repository, memory, compaction, and verify. No default
      SDK feature pulls shell. Python wheel linkage is
      unchanged. coding.rs lives in the example package.
