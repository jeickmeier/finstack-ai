Scope reviewed

- Agent/bundle/capability JSON ingress, effective configuration and lock export.
- Child placement, parent/effect identity, tenant, authorization context,
  reservation ordering, exact start-or-attach acceptance, and replay conflict.
- Budget reserve/reconcile/charge/release request and receipt integrity.
- Artifact scope, staging order, metadata/content integrity, size rejection,
  orphan collection, retention pinning, and read authorization.
- Capability activation rebuild, middleware-chain digest, compactor validation,
  and reserved Model activation.
- SEC-INV-001/002/004/005/007/008/010/012 and TM-04/TM-15/TM-16/TM-20.

PASS - TM-04 / SEC-INV-005 secret containment

AgentSpec, BundleSpec, and ResolvedAgentLock are data-only and credential-free.
Effective configuration recursively rejects suspicious secret-bearing fields;
explicit `_ref` values remain opaque host references. Resolution errors and
locks contain identifiers/digests rather than raw configuration. The repository
secret scan and canary task pass at the immutable candidate.

PASS - TM-15 / SEC-INV-002/004/008 child authority and ordering

The parent commits one complete child locator plus any reservation request
before service I/O. Same-session children require a new lane in the parent
session; isolated and remote children require a distinct session, and remote
children require the exact non-secret route. Parent run/effect, tenant,
placement, locator, request digest, authorization context, deadline, budget,
and delegation reference are frozen before `start_or_attach`. Invocation is
blocked until any required reservation receipt is committed. Equal retries
attach; conflicting digests fail in the replay-derived parent index. No global
run-ID scan is used.

PASS - TM-16 / SEC-INV-007/010 bounded strict ingress and replay

Strict Serde rejects unknown fields and unsupported schema versions. Specs,
capabilities, configurations, budget counters, metadata, content, and artifact
bytes have explicit ceilings and reject rather than truncate. Kernel state v5
validates child placement, reservation linkage, exact request/usage/release
digests, settled prerequisites, terminal release, and incompatible replay.
Impossible state and conflicting durable identities fail closed.

PASS - TM-20 / SEC-INV-001/008 artifact scope and integrity

Artifact authority comes only from the authenticated `ArtifactScope`, never
from attributes. Required content is durably staged before a reference can be
journaled. Returned references must exactly preserve scope digest, content
digest, length, kind, media type, name, and attributes. Cross-scope, missing,
corrupt, and oversized cases fail. Test-owned lifecycle simulation proves
failed-append orphans are eligible for cleanup while committed/pinned content
is retained.

Architecture and residual-risk disposition

- The kernel remains synchronous, deterministic, and I/O-free. No seventh
  primary port or middleware stage was added.
- AgentInvoker, BudgetLedger, and ArtifactStore are optional resolved runtime
  services; their policy is not embedded in kernel state.
- Always and Application activation are implemented. Model activation remains
  explicitly reserved and rejected.
- No new trust class, remote registry, ambient authority, planning conflict,
  exception, or ADR trigger was found. Existing ADR-008, ADR-020, ADR-036, and
  ADR-037 receive partial implementation evidence; their later mapped work
  remains open.
- Hosted OS matrices and independent review are not claimed.
