# finstack-ai-kernel

Deterministic I/O-free semantic engine (T0). Not a user-facing constructor.

## Quick start

Use the public SDK guide and the native minimal starter:

- [Rust guide](../../docs/site/rust.md)
- `cargo run -p finstack-ai-native-examples --bin minimal --offline --locked`

See [trust levels](../../docs/site/security-trust-levels.md).
